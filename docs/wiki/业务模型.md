# 业务模型

> **已实现**（示例代码）：`Product`、`CartItem`（按 `user_id` 聚合为购物车视图）。  
> **规划中**：SKU、独立 Cart 头表、Order、User 等见下文「目标架构」。

## 当前实现关系

```
User (模拟, X-User-Id)
  └── * CartItem ──> Product
```

- 无独立 `cart` 表：购物车 = 某用户下全部 `cart_item` 行。
- 加购时从 `Product` 读取单价并写入 `cart_item.price_in_cents` 快照。

---

## 已实现实体

### Product（商品）

| Field | Type | Description |
|-------|------|-------------|
| id | Long | 商品 ID |
| name | String | 商品名称 |
| priceInCents | Integer | 价格（分）🔴 |
| category | String | 分类 |
| status | Integer | 0=下架，1=上架 |

### CartItem（购物车项）

| Field | Type | Description |
|-------|------|-------------|
| id | Long | 购物车项 ID |
| userId | Long | 用户 ID |
| productId | Long | 商品 ID |
| quantity | Integer | 数量 |
| priceInCents | Integer | 加购时单价快照（分）🔴 |

## 目标架构（规划中）

```
User 1--* Cart 1--* CartItem --* ProductSku
  ├─1:* Order 1--* OrderItem --* ProductSku
  └─1:* ShippingAddress

Product 1--* ProductSku
```

### ProductSku（规划）

| Field | Type | Description |
|-------|------|-------------|
| id | Long | SKU ID |
| productId | Long | 所属商品 ID |
| skuName | String | SKU 名称 |
| priceInCents | Integer | 价格（分） |
| stock | Integer | 库存 |

订单与订单项、状态机见 `领域术语.md` 状态术语表。
