## 已实现表结构

### product（商品表）

| Column | Type | Nullable | Default | Description |
|--------|------|----------|---------|-------------|
| id | BIGINT | NO | AUTO_INCREMENT | 主键 |
| name | VARCHAR(128) | NO | - | 商品名称 |
| price_in_cents | INT | NO | - | 价格（分）🔴 |
| category | VARCHAR(64) | YES | - | 分类 |
| status | TINYINT | NO | 1 | 0=下架，1=上架 |
| is_deleted | TINYINT | NO | 0 | 软删除 |
| created_at | TIMESTAMP | NO | CURRENT_TIMESTAMP | 创建时间 |

**Indexes:** `PRIMARY (id)`

---

### cart_item（购物车项表）

| Column | Type | Nullable | Default | Description |
|--------|------|----------|---------|-------------|
| id | BIGINT | NO | AUTO_INCREMENT | 主键 |
| user_id | BIGINT | NO | - | 用户 ID |
| product_id | BIGINT | NO | - | 商品 ID |
| quantity | INT | NO | 1 | 数量 |
| price_in_cents | INT | NO | - | 加购时单价快照（分）🔴 |
| is_deleted | TINYINT | NO | 0 | 软删除 |
| created_at | TIMESTAMP | NO | CURRENT_TIMESTAMP | 创建时间 |
| updated_at | TIMESTAMP | NO | CURRENT_TIMESTAMP | 更新时间 |

**Indexes:**

| Name | Columns | Type |
|------|---------|------|
| PRIMARY | id | PRIMARY |
| uk_cart_item_user_product | user_id, product_id | UNIQUE |
| idx_cart_item_user_id | user_id | INDEX |

---
