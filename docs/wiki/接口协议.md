# 接口协议

## 通用约定

### Base URL

| 环境 | URL |
|------|-----|
| Development | `http://localhost:8080` |
| Production | `https://api.skyworkshop.com`（规划） |

### 请求头

| Header | Required | Description |
|--------|----------|-------------|
| Content-Type | Yes（有 Body 时） | `application/json` |
| Authorization | 生产必填 | `Bearer {token}`；**示例环境可省略** |
| X-User-Id | 购物车接口必填（示例） | 模拟登录用户 ID，默认 `1` |
| X-Request-Id | No | 请求追踪 ID |

### 统一响应格式

```json
{
  "code": 200,
  "message": "success",
  "data": {}
}
```

| Field | Type | Description |
|-------|------|-------------|
| code | Integer | 业务状态码（200 成功；40401 等见 ErrorCode） |
| message | String | 状态描述 |
| data | T | 业务数据 |

### 分页响应

```json
{
  "code": 200,
  "message": "success",
  "data": {
    "list": [],
    "total": 100,
    "page": 1,
    "size": 20
  }
}
```

### 错误码范围

| Range | Category |
|-------|----------|
| 200 | 成功 |
| 400 | 参数错误 |
| 404 | 资源不存在 |
| 40401 | 商品不存在 |
| 500 | 服务端错误 |

## 商品模块 API（已实现）

### GET /api/v1/products

获取商品列表（分页）

**Query Parameters**

| Param | Type | Required | Description |
|-------|------|----------|-------------|
| page | Integer | No | 页码，默认 1 |
| size | Integer | No | 每页数量，默认 20，最大 100 |
| category | String | No | 分类筛选 |
| keyword | String | No | 关键词搜索 |

**Response `data`**

```json
{
  "list": [
    {
      "id": 1,
      "name": "无线蓝牙耳机",
      "priceInCents": 19900,
      "category": "电子产品",
      "status": 1
    }
  ],
  "total": 5,
  "page": 1,
  "size": 20
}
```

### GET /api/v1/products/{id}

获取商品详情（仅上架商品）

### POST /api/v1/products

创建商品

**Request Body**

```json
{
  "name": "商品名称",
  "priceInCents": 9900,
  "category": "电子产品"
}
```

## 购物车模块 API（已实现）

> 示例项目用 `X-User-Id` 模拟登录，上线前须替换为 JWT（见 `安全规范.md`）。

### GET /api/v1/cart

获取当前用户购物车

**Headers:** `X-User-Id: 1`（可选，缺省为 1）

**Response `data`**

```json
{
  "items": [
    {
      "productId": 1,
      "name": "无线蓝牙耳机",
      "quantity": 2,
      "priceInCents": 19900,
      "subtotalInCents": 39800
    }
  ],
  "totalPriceInCents": 39800
}
```

### POST /api/v1/cart/items

加购

**Headers:** `X-User-Id: 1`

**Request Body**

```json
{
  "productId": 1,
  "quantity": 2
}
```

**行为：** 同一用户同一商品重复加购时数量累加；商品不存在或已下架返回 40401。

**Response `data`：** 与 `GET /api/v1/cart` 相同（加购后的完整购物车）。

### DELETE /api/v1/cart/items/{productId}

移除当前用户购物车中的指定商品。

**Headers:** `X-User-Id: 1`（可选，缺省为 1）

**Path：** `productId` — 商品 ID

**行为：** 按当前用户 + `productId` 定位并逻辑删除；不存在时返回 40402（`CART_ITEM_NOT_FOUND`）。

**Response `data`：** 与 `GET /api/v1/cart` 相同（移除后的完整购物车）。
