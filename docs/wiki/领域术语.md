# 领域术语

> skyworkShop 统一术语表。编码和文档须使用下表术语，禁止自造业务名词。

## 核心术语

| 术语 | 英文 | 定义 | 代码中的体现 |
|------|------|------|--------------|
| 商品 | Product | 可售卖商品（示例为 SPU 简化模型） | `Product`、`product` 表 |
| 购物车项 | CartItem | 用户购物车中的一条商品记录 | `CartItem`、`cart_item` 表 |
| 金额（分） | Cents | 所有金额以分为单位存储 | `priceInCents`、`price_in_cents` |
| 软删除 | Soft Delete | `is_deleted` 标记，不物理删除 | MyBatis-Plus `@TableLogic` |
| 快照 | Snapshot | 加购/下单时锁定单价 | `cart_item.price_in_cents` |
| 分类 | Category | 商品分类 | `category` 字段 |

## 状态术语（订单，规划）

| 术语 | 枚举值 | 说明 |
|------|--------|------|
| 待支付 | PENDING_PAYMENT (0) | 订单已创建，等待支付 |
| 已支付 | PAID (1) | 支付完成 |
| 已发货 | SHIPPED (2) | 已发货 |
| 已完成 | COMPLETED (3) | 已收货 |
| 已取消 | CANCELLED (4) | 已取消 |

## 技术术语

| 术语 | 说明 |
|------|------|
| Cache Aside | 先读缓存，未命中读库并回填（购物车缓存规划见 changes） |
| 幂等 | 同一操作多次执行结果一致；MQ 消费者须实现 |
| 前向兼容 | 数据库变更不破坏旧代码 |
